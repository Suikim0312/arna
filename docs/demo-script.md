# Сценарий Demo Day (5–7 минут)

## До выступления (за 10 минут)

```bash
solana-test-validator --reset            # вкладка 1, не закрывать
anchor deploy                            # вкладка 2
cd app && npm run dev                    # вкладка 3
```

Откройте http://localhost:5173 → «Демо» → «Подготовить демо» (около 20 секунд). Оставьте вкладку на странице кошелька Даны. На всякий случай держите открытым `logs/demo.log`.

## На сцене

**0:00–0:45. Проблема.** «Мама отправляет студентке деньги на еду, а уходят они в игровой клуб. Компания даёт бюджет на обеды и собирает чеки руками. Фонд пишет отчёты, которые никто не может проверить. Деньги "на что-то" держатся на доверии.»

**0:45–1:30. Идея.** Главная страница, конверты. «Arna — кошелёк, где деньги лежат по конвертам. Правила задаёт владелец, а проверяет их программа в блокчейне. Обойти её не может даже разработчик.»

**1:30–4:30. Живое демо** (роль «Дана»):

1. Показать три конверта и список «Куда можно платить».
2. Книжный, 4 800 ₸, «Учебник». Ставится синий штамп ОПЛАЧЕНО, внизу печатается чек. «Это транзакция в блокчейне, вот ссылка.»
3. Игровой клуб, 3 000 ₸. Красный штамп ОТКЛОНЕНО: «нет в списке». «Не приложение запретило, а программа: такого получателя для неё просто не существует.»
4. Городской транспорт, 9 000 ₸ при лимите 8 000. ОТКЛОНЕНО: «превышен лимит конверта».
5. Переключиться на «Маму», вкладка «Управление», поставить на паузу. Вернуться к «Дане», попробовать оплатить: ОТКЛОНЕНО. Снять с паузы.
6. «Наблюдатель»: тот же кошелёк без подключения. «Эту ссылку можно дать спонсору или жертвователю: все чеки видны, подделать их нельзя.»

**4:30–5:30. Как устроено.** Слайд архитектуры: PDA-хранилище, проверки в `spend`, CPI с `invoke_signed`, 19 тестов.

**5:30–6:30. Дальше.** Компании (обеды, обучение), фонды, гранты. QR-оплата в магазине, USDC, мультиподпись.

## План Б

- Приложение не грузится: `npm run demo` в терминале, тот же сценарий с отказами и подписями.
- Валидатор упал: `solana-test-validator --reset`, `anchor deploy`, «Подготовить заново».
- Ничего не работает: скриншоты в презентации и `logs/demo.log`.
